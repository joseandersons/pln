# Atividades de Processamento de Linguagem Natural

Repositório das atividades de PLN.

- [Atividade 1](atividade_1/README.md): seis exercícios de validação, expressões regulares e processamento de tweets.
  - [Notebook executado](atividade_1/atividade_1_senha.ipynb).
- [Atividade 2](atividade_2/README.md): similaridade entre documentos, classificação de texto e modelagem de tópicos.
  - [Notebook executado](atividade_2/atividade_2_topicos.ipynb).
- [Atividade 3](atividade_3/README.md): agrupamento com k-means e silhueta, projeção t-SNE, buscadores com word2vec, classificação com LSTM e Conv1D e análise com spaCy e grafos de entidades.
  - [Notebook executado](atividade_3/atividade_3_agrupamento_busca.ipynb).

Cada atividade reúne seu enunciado, notebook, base de dados e resultados na própria pasta.
