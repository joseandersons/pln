# Base de textos

Arquivo: `Tweets.csv`, cópia idêntica do arquivo usado na Atividade 1.

Fonte informada: [Twitter US Airline Sentiment — Kaggle](https://www.kaggle.com/datasets/drnimishadavis/twitter-us-airline-sentiment).

As questões 1, 2 e 3 usam a coluna `text`, pré-processada com a mesma função da Questão 5 da Atividade 1. A Questão 2 usa também a coluna `airline_sentiment` (positivo, neutro, negativo) como rótulo de classificação.
